# Vendored skills

The skills in this directory are copied from
[vercel-labs/agent-skills](https://github.com/vercel-labs/agent-skills)
at commit `063bee94c3f4df8453406c830b0a7df0f2860278`, licensed MIT.

Claude Code loads every `<name>/SKILL.md` here automatically when working in this repo.

| Skill | Use for |
| --- | --- |
| `composition-patterns` | React component composition patterns |
| `deploy-to-vercel` | Deploying apps to Vercel |
| `react-best-practices` | React / Next.js performance rules |
| `react-native-skills` | React Native / Expo best practices |
| `react-view-transitions` | React View Transition API animations |
| `vercel-cli-with-tokens` | Vercel CLI with token auth |
| `vercel-optimize` | Vercel cost and performance audits |
| `web-design-guidelines` | UI / accessibility / UX review |
| `writing-guidelines` | Docs and prose review |

To update, re-copy `skills/*` from the upstream repo (omit the `.zip` bundles).
